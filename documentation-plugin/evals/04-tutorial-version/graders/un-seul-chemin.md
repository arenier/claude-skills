Le tutoriel déroule-t-il un seul chemin, sans trace d'une version antérieure ?

Réponds FAIL seulement si tu peux citer, mot pour mot, une phrase du document qui :
- propose un autre chemin ou une option (« si tu as… », « tu peux aussi… », une variante selon la version installée), ou
- évoque une version antérieure de Mesure, sa fin de maintenance, ou ce qui a changé entre les versions.

Mentionner « Mesure 2 » comme la version installée n'est pas une trace d'une version antérieure. Sans phrase à citer, réponds PASS.
